## 这一版给谁用

慧尖 HA 语音加载项 **v1.7.6**（商店点"更新"即可）。本版**不含新固件**——可下发固件仍是
**v2.3.11**（镜像与校验值随 vo-1.7.5 发布挂在两侧 Release，下发账不变）。

⚠ **本版改了语音解析侧的 Python 行为：更新加载项后请再重启一次 Home Assistant**
（只重启加载项的话，新代码不会替换已加载的模块，你会以为"更新没用"）。

## 你听得出来的变化

1. **"我家/咱家/我们家 + 房间"这种说法能听懂了。**
   以前说「我家办公室的射灯打开」，它会去找一间叫「我家办公室」的房间，找不到就回
   「这个房间在 Home Assistant 里不存在」；或者说「我家客厅的灯打开」得到同样的话。
   现在它会正确落到"办公室""客厅"那间房。
2. **「家里 + 房间 + 设备」不再动错范围。**
   「家里阳台的窗帘拉上」以前会把"阳台"丢掉、按**全屋窗帘**执行（＝顺手拉了别的房间的窗帘），
   现在只动阳台那一组。
3. **「家里的灯打开」这类真·全屋说法照旧是全屋**，没有被上一条改坏——"家里"后面没有具体房间时，
   它仍然理解成整套房子。
4. **「打开我们家的灯」不再被当成"点名了一台叫『家的灯』的设备"**，不会再回
   「没有找到对应的设备『家的灯』」；这句现在按"家里的灯"走（该出歧义列表就出列表）。
5. **问句里的房间也对了**：「我家客厅的灯开着吗」「我们家办公室的灯开着吗」这类查询，
   以前可能抽出一个谁也没说过的房间名（甚至被削成"们家办公室"），现在按真房间查。

## 顺带闭掉的发布面问题

- Release 正文长度闸：上一版（1.7.5）发布后补的变更记录把正文顶过了提取上限，
  那道闸当场拦红——本版把上限抬高，**没有删任何一条判决记录**。

## 这一版**没有**声称做到的（避免你按错的预期验收）

- 台架**真机臂**（播音 → 设备听 → 识别）本轮未跑：本机 Kokoro 语音合成模型未就绪，
  合不出音频，工装拒绝出伪结果。跑的是 dry 臂 23 格（含为本版新增的属格那一格），
  真机区域表上判绿；同一格在 1.7.5 字节上判红（证明这条修复是真的在起作用，不是自说自话）。
- 「卧室关灯」这类**不带"我家"、也不带"的"**的说法，仍会把"卧室"当设备名去找
  （这是解析面另一条既有道，与本版修的属格族无关，需要台架/现网进一步定标）。
- 远程控制的可用性判定、跨仓契约用例在 CI 里仍是跳过分支（需要给仓库配两把只读部署密钥），
  本版没有把它写成已验。
