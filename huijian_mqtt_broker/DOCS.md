# 慧尖 LoRa 网关（huijian_mqtt_broker）

慧尖开窗器 LoRa 网关的 Home Assistant 一体化加载项：装一个就得到
**内置 MQTT Broker（:2022）+ 网关集成 + 管理面板 + 小慧语音小程序局域网直连 + 慧尖云远程控制**。
日常控制全部在局域网内完成，云端只承担"人不在家时的小程序远程"。

> 本文件写给**装机器的人**；开发者文档见 [ARCHITECTURE.md](ARCHITECTURE.md)，
> 版本历史见 [../CHANGELOG.md](../CHANGELOG.md)，第三方许可见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

## 前置要求（先确认这一条，能省一次报障）

本加载项**只能装在 Home Assistant OS（HAOS）或 Supervised 形态**上——因为只有这两种形态
有「加载项商店」。

| 你的 HA 形态 | 能不能装 | 说明 |
|---|---|---|
| Home Assistant OS（树莓派、NUC、NAS 上的 HAOS 虚拟机等） | ✅ | 官方推荐形态 |
| Home Assistant Supervised | ✅ | |
| Home Assistant Container（Docker / 群晖套件 / 威联通 Container） | ❌ | 没有 Supervisor，没有加载项商店，**也没有手装的等价路径** |
| Home Assistant Core（pip 直装） | ❌ | 同上 |

怎么看自己是哪种：HA 左侧 **设置 → 系统 → 关于**，能看到「加载项商店」这一项就有 Supervisor。
或者在 **设置 → 系统 → 修复与备份** 里看到「冷备份/活动备份」字样，也是 HAOS。

另外需要：
- 一台已配网的慧尖开窗器 LoRa 网关（固件内置连接参数，**网关侧不需要填任何东西**）；
- 网关与 HA 主机在**同一个局域网**（同一二层广播域）；
- 手机微信里的小程序「**小慧语音**」（这是微信里的搜索名，搜「慧尖」搜不到）。

## 安装（3 步 + 1 次重启）

1. **添加仓库**：设置 → 加载项 → 加载项商店 → 右上角 ⋮ → 仓库，添加
   `https://github.com/fangwenyi-dev/HJKJ`。
   GitHub 拉不动时改用 Gitee 容灾源 `https://gitee.com/fangwenyi-dev/HJKJ`（逐提交同步）。
   **二选一、勿同加**——两个地址在 Supervisor 里是两张独立的卡，会互相抢端口。
2. **安装并启动**：商店搜「慧尖」→ 进「慧尖 LoRa 网关」卡片 → 安装 → 启动。
   配置页**全部字段都不用改**（默认值即为出厂约定值）。
3. **重启一次 HA Core**（仅首次安装必须）：集成代码由加载项落盘，HA 启动时才加载它。

启动后全自动：Broker 监听 2022、mDNS 广播 `huijian.local`、HA 的 MQTT 集成自动指向内置
broker、网关集成自动落盘、ACL 用户隔离自动创建。

## 添加网关

LoRa 网关**上电即被自动发现**：HA 弹出「发现慧尖 LoRa 网关」卡片，点「添加」并确认即完成。

> 自 v1.7.62 起**每一台**（含第一台）都需要你在卡片上点一次确认，不再静默自动添加。
> 没点确认的网关不会建实体——这是有意保留你的确认权。

也可以手动加：设置 → 设备与服务 → 添加集成 → 搜「慧尖」。

## 排障（按现象找，别按部件找）

**商店里找不到「慧尖 LoRa 网关」卡片**
先看 Supervisor 日志（设置 → 系统 → 修复与备份 → 右上角 查看系统日志）里有没有
`Can't read .../config.yaml`。加载项仓库清单是"整份校验失败即整体静默跳过"，前端不报错。
本仓有钉桩防线；如果你加的是 fork/改版仓库，请以本仓地址为准。

**安装一直停在"下载镜像"或报 `connection reset`**
镜像主源走国内透传镜像（`ghcr.1ms.run`）。① 等 1 分钟重试——新版发布后边缘缓存同步有短暂
窗口；② 仍失败就在加载项详情页「配置 → 高级 → 镜像(Image)」把域名改成备选源，例如
`ghcr.nju.edu.cn/fangwenyi-dev/amd64-huijian-mqtt-broker`（树莓派等写 `aarch64`），改完重新
点安装；③ 商店 ⋮ → 检查更新后再试。

**刚出新版点「更新」报 `An unknown error occurred with app …`**
版本号进入商店 git 后，镜像还要几分钟才经 CI 构建推送完。点太快会拉到不存在的镜像 tag。
**等十几分钟再点一次「更新」即可**，不是加载项故障。

**网关上电了但 HA 没有弹卡**
① 确认网关与 HA 同网段（跨 VLAN / 访客 WiFi 收不到 mDNS）；② 确认加载项在"运行中"；
③ 看加载项日志有没有 `[发现代理] 启动` 一行；④ 换路径：设置 → 设备与服务 → 添加集成 →
搜「慧尖」手动填 HA 地址。

**面板远程控制面板显示「云端暂时连不上」**
这是**连接兜底文案**，含义是加载项连不上慧尖云，原因多为云端正在发版或本机网络不通。
- **局域网控制不受影响**：小慧语音在同网段时直连 `ws://<HA>:9001/ws`，不走云。
- 加载项会自动重试（退避 5 秒到 5 分钟），一般几分钟内自己恢复。
- 只有当它同时显示「需要重新扫码绑定」/「云端不认识本机身份」这类**具体**文案时，才需要
  你重新点二维码换新码让家人重扫。

**小程序扫码后家人列表里没人 / 扫码失败**
绑定码是一次性、约 10 分钟有效（有效期以云端回的为准，面板上会显示剩余时间）。
过期就点二维码换一张重扫。

**小程序里设备列表"停在昨天"、但人在家用 HA 或局域网小程序能正常控制**
这是加载项**故意不上传**这一批快照：它判断本批不是"当前全部设备"（某台网关条目还没挂上、
或某台的状态视图构造失败），而云端是按"这批就是全量"来淘汰已删除设备的——把残缺的批次交出去，
那些设备会在家人手机上**被真删掉**。所以宁可停在上一批。
- 数据不会丢，本地控制不受影响；条目挂齐后下一轮（最长约 5 分钟保活）自动恢复。
- 要确认是不是这一条：加载项日志里找
  `hub 状态快照不完整（网关条目未挂上或视图构造失败），本轮不上行；恢复前云端设备列表停在上一批`。
- 长期不恢复（比如某台网关的配置条目被禁用）：设置 → 设备与服务 里确认每台慧尖网关条目都是"已加载"，
  再重启一次加载项。

**一台局域网里有两台 HA 都装了本加载项**
第二个的 mDNS 广播会**响亮报错并退避**：加载项日志出现
`[mDNS] 广播因名字冲突退出（同局域网另一台慧尖加载项占着 huijian.local）——重试不会成功，
请按上一行提示二选一处理`，之后按指数退避（最长 10 分钟）再探一次。名字是永久被另一台占着的，
所以不会静默抢名，也不会自己修好。家庭场景只需要一台——请只保留一台。
两台之间**本地控制不受影响**，受影响的是"网关自动发现"（网关只会连它解析到的那一台）。

## 反馈怎么给（报障请带这三样）

不管走哪个渠道，这三样齐了基本能一次定位：

1. **加载项版本**：管理面板页头，或 设置 → 加载项 → 慧尖 → 顶部版本（形如 `1.8.7`）；
2. **网关固件版本**：管理面板按设计**不显示**固件号（终端用户没有升级固件的处置入口，显示只会
   造成困惑）。要取的话从加载项/HA 日志里该网关上报行的 `fw` 字段抄，或从小慧语音小程序看；
3. **日志片段**：加载项详情页「日志」标签，从"启动"起到出问题那一段（含 `文件:行号` 更好）。

再加一句"什么时候出现的、当时做了什么操作"。

当前可用渠道：
- 问题跟踪：<https://github.com/fangwenyi-dev/HJKJ/issues>（GitHub 账号可提）；
- 购买/售后渠道（企业客服、电话、邮箱）：**随整机说明书发布，尚未写进本仓文档**。

> 管理面板在 `registry_full` 等场景会提示"请联系慧尖"，指向上面的问题跟踪地址。

## 能力与边界（诚实清单）

这些不是待修的 bug，是当前的设计取舍，买前请知道：

- **局域网内 MQTT 是明文、凭据全网同一份**（`huijian`/`huijian2022`，端口 2022，写在公开仓库里，
  改动会在启动时被自动恢复）。原因：这套参数烧在网关固件里，改了就会把自家网关挡在门外。
  ⇒ 后果是**同一局域网内的任何设备都能读取网关上报、也能下发开窗指令**。
  请务必不要把 2022/9001 向公网映射；建议把网关与你的设备放在同一专用 SSID/VLAN，
  访客网段禁止访问这两个端口。
- **小程序 WS 网关默认开启，默认握手令牌也是公开值**。这一侧**可以收紧**：
  设置 → 设备与服务 → 慧尖 → 选项 → 高级选项 里改令牌（或在小慧语音内改，需先用当前令牌认证）。
  端口必须保持 9001（小程序与固件恒拨该口）。
- **远程控制走慧尖云**：加载项主动出站长连到慧尖在微信云托管上的一个服务。
  云端不可用时局域网控制照常，只是小程序远程不可用；本加载项不提供自建云端点入口。
- **管理面板只有中文**（侧边栏「慧尖网关」那页）；集成条目文案有中英两套翻译，跟随 HA 语言。
- **家庭成员上限 8 人**（该上限以云端回的值为准，云端没回时用本地兜底值）。
- 绑定码/成员码是一次性凭据、约 10 分钟有效：能拍到 HA 面板二维码的人就能成为家人，
  这是缓解不是防护。
- 上云的数据：网关注册信息（SN、固件版本）与设备状态快照（位置/电量/锁/速度等），
  用于小程序远程显示。**成员称呼只存在你家 HA 的配置目录，不上云**。
  目前没有"一行开关关掉遥测"的选项。

## 端口占用

| 端口 | 用途 | 暴露范围 |
|---|---|---|
| 2022 | 内置 Mosquitto MQTT Broker（网关接入、HA 的 MQTT 集成） | 宿主全网卡（明文，凭据固定） |
| 9001 | 小慧语音小程序 WS 网关（局域网直连） | 局域网，令牌握手 |
| 10998 | 管理面板 Ingress | 仅 HA / Supervisor 网段 |

## 升级

设置 → 加载项 → 慧尖 → 「更新」→ 重启加载项。**集成代码有变更时再重启一次 HA Core**
（Release 说明会标注）。网关与子设备的数据存在 HA 配置目录，升级不丢。
